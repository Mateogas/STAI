# Review HR clarifications before broader reuse

AISHA will retain every structured HR resolution as Case Resolution Memory for
follow-ups inside that Case Thread, but it will never learn a global rule from a
raw HR message. Only a reviewed Policy Clarification linked to existing policy
may supplement later answers, and it remains subordinate to the active handbook;
case exceptions stay case-scoped and Policy Amendment Candidates require a new
handbook revision. This preserves useful continuity without turning one support
interaction into unaudited policy authority.
