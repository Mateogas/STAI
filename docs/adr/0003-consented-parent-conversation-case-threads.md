# Mirror consented parent conversations into case threads

AISHA will represent an Escalation Case as a child Case Thread beneath its
originating Policy Conversation. Creating the case requires explicit notice that
the existing parent history and future parent messages will be shared with HR
until the case closes; HR reads the copied Case Thread rather than the private
policy-conversation tables. This trades the earlier summary-only handoff for
continuity and a Discord-style threaded experience while keeping certificate
content, HR-only notes, and unrelated conversations outside the shared thread.
